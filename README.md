# Bank-Card-transaction-Analysis
## 🎯 Project Objective
The objective of this project is to analyze bank card data using Microsoft Excel. The analysis focuses on card types, card brands, credit limits, chip availability, card issuance, account opening dates, and other relevant card attributes to generate meaningful business insights.
## 📊 Dataset Description
The dataset contains bank card information for different clients. Each row represents a card record and includes information such as card brand, card type, credit limit, chip availability, number of cards issued, account opening date, and card security information.
## 📋 Dataset Columns
| Column | Description |
|---|---|
| ID | Unique identifier for each card |
| Client ID | Unique identifier for each client |
| Card Brand | Brand of the card |
| Card Type | Type of card, such as Credit or Debit |
| Card Number | Card number |
| Expires | Card expiration date |
| CVV | Card verification value |
| Has Chip | Indicates whether the card has a chip |
| Number of Cards Issued | Number of cards issued |
| Credit Limit | Credit limit associated with the card |
| Account Open Date | Date when the account was opened |
| Year PIN Last Changed | Year when the PIN was last changed |
| Card on Dark Web | Indicates whether the card was found on the dark web |
